# 商业化业务看板

本次原型涉及投放商业化模块下的广告主账户管理、返点政策配置、商业化业务看板、返点变动差值看板、回款看板（回款主体汇总看板）、渠道及客户管理六个页面。

之前标签和广告主账户的映射关系是：商务维护【渠道及客户管理】里的字段，技术通过这个字段去方舟拉取广告主账号信息，通过标签对应广告主账户，维护到【广告主账户管理】。现在因为有些平台比如小红书不能给广告主账户打标签，所以要直接在我们系统【广告主账户管理】里直接维护，通过api接口去对接各个平台。
